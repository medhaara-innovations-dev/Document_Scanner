# FamilyKit responsive React landing page

This is a real JSX/CSS page, not a screenshot pasted into a browser. Sections, cards, text, navigation, and FAQs are separate DOM elements. Five illustrative assets were cropped from the user-provided desktop reference; source quality is limited by the screenshot resolution. Replace them with original artwork for closer visual fidelity.

## Run

Open this folder (the folder containing package.json) in VS Code and run:

```powershell
npm install
npm run dev
```

Visit http://localhost:5173/.

## Note

The early-access and contact email addresses are placeholders and should be replaced before launch. Security descriptions are reference design copy, not independently verified claims about the deployed application.
